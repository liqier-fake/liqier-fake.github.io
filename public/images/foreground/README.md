# Foreground cut-outs

Transparent near-plane artwork that stands between the camera and the live 3D world.

| File | Origin |
| --- | --- |
| `sakura-branch.webp`, `stone-lantern.webp`, `reeds.webp`, `pine.webp`, `paper-lanterns.webp`, `shore-rocks.webp`, `maple-leaves.webp` | Generated for this project with ChatGPT image generation (2026-11-03), original artwork, trimmed and converted to WebP. |

Replace any of them with your own artwork at the same filename; keep a real alpha channel and anchor the subject to the edge it grows from (bottom for plants and rocks, top for hanging branches and lanterns).
